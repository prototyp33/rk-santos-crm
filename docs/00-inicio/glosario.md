# Glosario

Las tablas que usan estos términos están en el [modelo de datos](../30-arquitectura/modelo-datos.md).

| Término | Significado |
|---|---|
| Pipeline | Ocho fases, en este orden: `circulo_influencia`, `prospecto`, `captacion`, `documentacion`, `publicacion`, `visitas`, `cierre`, `notaria` |
| `agent` | Ve y edita solo sus contactos, inmuebles, valoraciones y expedientes |
| `coordinator` | Revisa checklists y expedientes de la agencia. No cambia los parámetros del valorador |
| `supervisor` | Raúl Santos. Ve toda la agencia y es quien cambia los parámetros maestros del valorador |
| Inmovilla | Pasarela de publicación, web y MLS. Este CRM no la sustituye |
| Horus (Orus) | Plataforma de la red RK. Referencia de expediente y círculo. No es el registro de la valoración |
| Estimación comercial | Rango de precio de salida con fuentes y revisión humana. No es una tasación oficial |
| Precio de oferta | Precio publicado en un anuncio |
| Precio de cierre | Precio de una venta realizada |
| Precio de salida | Precio al que se recomienda publicar, tras la validación interna |
| Procedencia | `verificado`, `declarado` o `inferido` |
